# 会话消息书签插件：选中文字加书签，按项目分组查看，点击跳回原消息

更新：2026-10-21

## 路线

- [x] 阶段 1：核心 `feature/thread-message-navigation`，`BbNavigate.toThread` 支持 `experimental_messageSeq`（f7b53a6004）
- [x] 阶段 2：独立插件 `~/code/bb-plugin-bookmarks`（选区菜单加书签、侧栏底部与全页列表、CLI），dev 实例已验收（ecd59a4）
- [x] 阶段 3：分支登记 `.fork/branches`，聚合打包发布，部署后在本机 BB 安装插件，补测真实 assistant 选区菜单（本机已安装，实测通过）
- [x] 阶段 4：入口改为右侧面板标签页（默认当前项目，可取消过滤看全部；加书签后自动打开并定位），移除侧栏底部与全页入口，支持 GitHub 直装，生产已从 GitHub 安装实测（3ab1b9a）
- [x] 阶段 5：曾支持界面中英文（阶段 7 按用户要求移除）；修复会话标题未命名（9f7b9d1，生产已更新）
- [x] 阶段 6：右侧常驻书签标签与复制/备注/删除的悬停、指针及键盘焦点反馈；核心 `feature/plugin-pinned-thread-panels` 提供通用 `experimental_pinned`，插件自行启用（核心 09bc4d7824，插件集合 b2bcbba；已发布并部署 `fork-v0.46.1-20261021.1`）。浏览器实测无需“+”、刷新不重复、旧标签与选择保留、关闭快捷键收起面板、按钮反馈、复制文字与备注取消；书签数据、配置及插件启停状态不变。
- [x] 阶段 7：取消双语支持，界面与日期统一英文，移除语言设置及自动判断（插件 0.1.3，集合 0517f06）。当前实例已热更新，中文和英文浏览器均显示英文，常驻标签和书签数据核对正常。

## 关键决策

- 2026-10-21 用户决定取消书签插件的双语支持，与 BB 本体统一使用英文；移除语言设置、浏览器语言判断和中文界面文案，保留历史中文标题占位值的修复与用户保存的内容。

- 2026-10-21 用户要求书签常驻会话右侧，不再经“+”添加。固定只作用于默认标签，不强行展开面板或切换当前选择；注册释放后恢复普通可关闭标签。书签启用与按钮交互样式在集合维护，核心仅提供通用标签固定选项。

- 2026-10-17 用户追加迁入统一插件集合 hxy91819/bb-plugins，覆盖此前独立仓库的维护选择；保持 bookmarks ID、数据格式和中英文设置。原因：统一维护。影响：安装来源迁移与配置保留，旧仓库保留历史。

- 2026-10-15 跳转靠核心扩展 `toThread` 的 `experimental_messageSeq`，与命令面板会话搜索共用实现。原因：插件无路由访问，不做 hash hack。影响：阶段 1、2。
- 2026-10-15 插件做成仓库外独立本地插件，只依赖公开 SDK。原因：用户选择。影响：阶段 2、3。
- 2026-10-15 定位粒度到消息，不高亮句子；选区菜单只覆盖 assistant 回复，用户消息用整条消息按钮。原因：现有 API 能力。影响：阶段 2。
- 2026-10-16 fork 只保留 fork-release.yml 启用，其余上游 workflow 手动停用。原因：blacksmith runner 不可用致空排队，触发 GitHub 停跑。影响：发布。
- 2026-10-16 书签唯一 UI 入口是会话右侧面板标签页，默认过滤当前项目，取消过滤显示全部；不保留侧栏底部与全页列表。原因：用户选择。影响：插件 UI。
